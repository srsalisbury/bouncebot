# BounceBot Client

The Vue 3 + TypeScript frontend for BounceBot. Provides the interactive game board, room lobby, and daily challenge UI.

For the full client documentation, see **[docs/client.md](../../docs/client.md)**.

For architecture context, see **[docs/architecture.md](../../docs/architecture.md)**.

## Quick Start

```bash
cd client/web
npm install
npm run dev
```

The app starts at `http://localhost:5173`.

## Tests

```bash
npm test
```
